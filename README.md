# Academia de Modelaje Indígena

Un sitio web moderno y dinámico para una academia especializada en modelaje para pueblos indígenas, promoviendo la belleza ancestral y la diversidad cultural.

## 🎨 Características

- **Diseño Responsivo**: Optimizado para todos los dispositivos
- **Paleta de Colores Indígena**: Colores inspirados en la cultura ancestral
- **Animaciones Suaves**: Transiciones y efectos visuales atractivos
- **SEO Optimizado**: Meta tags y estructura optimizada para motores de búsqueda
- **Rendimiento**: Carga rápida y optimizada
- **Accesibilidad**: Diseño inclusivo y accesible

## 🚀 Stack Tecnológico

- **Framework**: Next.js 14 con App Router
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Animaciones**: Framer Motion
- **Iconos**: Lucide React
- **Gestor de Paquetes**: pnpm
- **Linting**: ESLint

## 📦 Instalación

1. **Clonar el repositorio**
   ```bash
   git clone <repository-url>
   cd academia-modelaje-indigena
   ```

2. **Instalar dependencias con pnpm**
   ```bash
   pnpm install
   ```

3. **Ejecutar en modo desarrollo**
   ```bash
   pnpm dev
   ```

4. **Abrir en el navegador**
   ```
   http://localhost:3000
   ```

## 🏗️ Scripts Disponibles

- `pnpm dev` - Ejecuta el servidor de desarrollo
- `pnpm build` - Construye la aplicación para producción
- `pnpm start` - Ejecuta la aplicación en modo producción
- `pnpm lint` - Ejecuta el linter
- `pnpm type-check` - Verifica los tipos de TypeScript

## 🎨 Paleta de Colores

La paleta está inspirada en la cultura indígena:

- **Primary**: Tonos terracota y naranja cálido
- **Earth**: Colores tierra y marrones naturales
- **Sage**: Verdes salvia y tonos naturales
- **Sunset**: Naranjas y rojos del atardecer
- **Clay**: Tonos arcilla y beige

## 📱 Secciones del Sitio

1. **Hero**: Sección principal con estadísticas y llamada a la acción
2. **Academia**: Información sobre la academia y su metodología
3. **Equipo**: Presentación del equipo de trabajo
4. **Estudiantes**: Galería de estudiantes con filtros por categoría
5. **Competencias**: Logros y competencias de los estudiantes
6. **Contacto**: Formulario de contacto e información de contacto

## 🔧 Configuración

### Variables de Entorno

Crea un archivo `.env.local` con las siguientes variables:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_CONTACT_EMAIL=info@academiaindigena.com
```

### Personalización

- **Colores**: Modifica `tailwind.config.js` para cambiar la paleta
- **Contenido**: Edita los componentes en la carpeta `components/`
- **Imágenes**: Reemplaza las imágenes placeholder con imágenes reales

## 📈 Optimizaciones

- **Imágenes**: Optimización automática con Next.js Image
- **Código**: Tree shaking y code splitting automático
- **CSS**: PurgeCSS para eliminar estilos no utilizados
- **Bundle**: Análisis de bundle size optimizado
